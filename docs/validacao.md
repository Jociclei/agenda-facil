# Plano de validação do Agenda Fácil

## Objetivo

Descobrir se prestadores de serviços enfrentam problemas de organização de agendamentos e se o protótipo ajuda a resolver parte desses problemas.

## Perguntas de entrevista

1. Como você organiza os agendamentos hoje?
2. O que costuma ser mais difícil nessa organização?
3. Já perdeu ou confundiu um horário por falha de comunicação?
4. Como os clientes costumam solicitar atendimento?
5. O que uma ferramenta simples precisaria fazer para ser útil?
6. Você testaria uma página para receber solicitações?
7. O que faria você considerar pagar por uma ferramenta assim?

## Hipóteses e metas experimentais

| Hipótese | Método | Meta inicial |
|---|---|---|
| O problema é frequente | Entrevistar 10 profissionais | 7 relatam o problema espontaneamente |
| O formulário é compreensível | Testar com 10 pessoas | 8 concluem sem ajuda |
| O painel ajuda a acompanhar pedidos | Demonstrar a 5 profissionais | 4 identificam utilidade prática |
| Existe interesse em testar | Convidar profissionais | 5 aceitam experimentar |
| Existe disposição para pagar | Apresentar uma proposta de preço | Registrar respostas concretas, sem presumir compra |

Essas metas são critérios de aprendizagem, não resultados alcançados.
